# MAVEN - Modern E-Commerce Experience

MAVEN is a premium, minimalist e-commerce platform modernized for a seamless shopping experience.

WEBSITE : https://vismay-dev1.github.io/MAVEN-ecommerce/

## Features

- **Modernized UI/UX**: Clean, high-end aesthetic using Montserrat and Playfair Display typography.
- **Dark Mode**: Fully functional, persistent dark mode support across all pages.
- **Indian Market Localization**: Prices in INR (₹) with localized shipping and payment methods (GPay, COD).
- **Full Shopping Funnel**:
    - **Homepage**: Hero banners, category showcases, and advanced filtering/sorting.
    - **Product Detail**: Image galleries with zoom, size guides, and interactive specifications.
    - **Shopping Cart**: Real-time total calculation, free shipping thresholds, and promo code support.
    - **Checkout**: Multi-step process (Shipping -> Method -> Payment -> Review).
    - **Account Management**: User dashboard, order history, and saved preferences.
- **Global Search**: Search for products from any page with automatic redirection to the shop section.
- **Responsive Design**: Optimized for Mobile, Tablet, and Desktop.
- **Performance**: Lazy loading for images, debounced search, and optimized asset delivery.

## Technology Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3**: Modular design system with CSS Variables and advanced animations.
- **JavaScript (Vanilla)**: Robust state management using `localStorage` (No external frameworks required).

## Setup & Usage

1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Use the Search or "Shop Now" buttons to explore the 25-item product database.
4. Use the theme toggle in the header to switch between Light and Dark modes.

## Code Structure

- `index.html`: Main storefront and landing page.
- `product.html`: Detailed product views and interactive selectors.
- `cart.html`: Shopping cart management.
- `checkout.html`: Secure multi-step checkout flow.
- `account.html`: User profile and order management.
- `style.css`: Unified design system and dark mode variables.
- `script.js`: Core application logic, product database, and state management.
