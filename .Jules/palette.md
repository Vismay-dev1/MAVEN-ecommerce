## 2025-05-14 - [Focus States & Keyboard Accessibility]
**Learning:** Modern premium e-commerce sites often disable default browser outlines for aesthetic reasons, but this completely breaks keyboard navigation. Using `:focus-visible` allows for a beautiful, branded focus indicator that only appears for keyboard users, preserving aesthetics for mouse users while ensuring accessibility.
**Action:** Always implement `:focus-visible` when disabling default outlines, and ensure the focus indicator has high contrast and matches the brand's design system.
